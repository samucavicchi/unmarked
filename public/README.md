# Cartella `public/`

I file in questa cartella sono serviti **tal quali** dalla root del sito.
Esempio: `public/hero.jpg` → accessibile via `/hero.jpg`.

## File richiesti

- **`hero.jpg`** ← **DA INSERIRE**
  La foto della felce della homepage.
  Salvala con questo nome esatto, in questa cartella, prima di committare.
  Larghezza consigliata 2400px, peso < 500 KB.

## File già presenti

- `favicon.svg` — Icona del sito (la "U" su sfondo cream). Sostituibile con un design definitivo.
